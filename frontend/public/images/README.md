# Image Assets

Place your millet images here with the following names:

1. **ragi-plant.jpg** - Finger Millet (Ragi) plant image
2. **foxtail-millet.jpg** - Foxtail Millet plant image  
3. **pearl-millet.jpg** - Pearl Millet (Bajra) plant image
4. **millet-grain.jpg** - Millet grains in a bowl/container

**Recommended specifications:**
- Format: JPG or PNG
- Resolution: 800x600 or higher
- File size: Optimize for web (under 500KB each)
- Quality: High quality, well-lit images

These images will be used in the About section and throughout the landing page with smooth animations.
