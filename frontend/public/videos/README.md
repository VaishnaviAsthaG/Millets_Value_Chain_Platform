# Video Assets

Place your background video file here:

- **File name**: `agriculture-sunset.mp4`
- **Recommended format**: MP4 (H.264 codec)
- **Resolution**: 1920x1080 or higher
- **Duration**: 10-30 seconds (will loop)
- **Size**: Optimize for web (under 5MB if possible)

The video should show:
- Sunset over grain crops / golden agriculture scene
- Smooth, cinematic quality
- Suitable for background use

If you don't have a video, the page will fall back to a gradient background.
